- **reads**: "source-citation@1.0.0", "figure-region@1.0.0", "impress/artifact/general"
- **writes**: —
- **reach**: —

| Argument | Type | Required | Description |
|---|---|---|---|

**Examples**

## `source-service_get-figure-image`

Resolve a stored figure boundary and return its crop as MCP image content. Use this for a cited figure; use get-page-image for context. Uncertain boundaries return the complete page as an explicit fallback.

- **safety**: `external`
- **reads**: target(source_item_id), "figure-region@1.0.0", "source-citation@1.0.0", "imbib/linked-file"
- **writes**: —
- **reach**: subprocess, fs

| Argument | Type | Required | Description |
|---|---|---|---|
| `citation_id` | — | no | UUID of a stored citation; supply this or `source_item_id`, not both. |
| `figure_label` | string | yes | Figure label as recorded in its source region, such as `Fig. 1`. |
| `format` | — | no | Image format; currently `png`. |
| `include_caption` | — | no | Include caption geometry in the crop; defaults to true. |
| `padding` | — | no | Extra crop padding in pixels, capped at 256. |
| `resolution_dpi` | — | no | Render resolution in dots per inch; omit for the 200 DPI default. |
| `source_item_id` | — | no | UUID of the source PDF; supply this or `citation_id`, not both. |

**Examples**

- `render_fixture_figure_tier_b` — Tier B (isolated host):

  ```json
  {"source_item_id":"57000000-0000-4000-8000-000000000001","figure_label":"Fig. 1","resolution_dpi":150,"format":"png"}
  ```
  expects:

  ```json
  {"ok":true,"status":"resolved","metadata":{"figure_label":"Fig. 1","mime_type":"image/png"}}
  ```

## `source-service_search-content-chunks`

Search extracted source text while preserving page/figure/table locators and extraction lineage. An optional source UUID confines the results to one asset; pass null to search all ingested sources.

- **safety**: `read_only`, idempotent
- **reads**: any("full-text search inspects all indexed kinds before filtering to source chunks")
- **writes**: —
- **reach**: —

| Argument | Type | Required | Description |
|---|---|---|---|
| `limit` | integer | yes | Maximum hits, capped at 50; zero uses the default of 10. |
| `query` | string | yes | Text to match against indexed source chunks. |
| `source_item_id` | — | no | Restrict results to this source asset UUID; omit to search all ingested sources. |

**Examples**

- `find_fixture_chunk` — Tier A:

  ```json
  {"query":"effects","source_item_id":"57000000-0000-4000-8000-000000000001","limit":5}
  ```
  expects:

  ```json
  {"ok":true,"hits":[{"chunk_id":"57000000-0000-4000-8000-000000000004"}]}
  ```
