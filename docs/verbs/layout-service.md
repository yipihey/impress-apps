## `layout-service_apply-layout`

Recall a saved layout by `name` (or id), or by `ordinal` 1–9 — the ⌃⌘1–9 chords.

An ordinal numbers ONE union: this app's **presets** first, in the shipped table's order, then its named layouts, oldest first. So ⌃⌘1 is always the app's default arrangement and ⌃⌘2 its Triage, whatever the user has saved since. A `name` that is a preset rather than a layout applies that preset, for the same reason: a palette types into one name space.

Window geometry is dropped on the way in: the logical tree is what ports between devices, and a 27" frame has no business landing on a laptop (ADR-0019 D2).

- **safety**: `destructive`
- **reads**: "impress/ui/layout@1.0.0", "impress/ui/preset@1.0.0"
