## `settings-service_get`

One setting's current value and where it came from.

- **safety**: `read_only`, idempotent
- **reads**: "impress/settings@1.0.0"
- **writes**: —
- **reach**: fs

| Argument | Type | Required | Description |
|---|---|---|---|
| `key` | string | yes | The registry key. |

**Examples**

- `inbox_days` — Tier A:

  ```json
  {"key":"imbib.retention.inbox_days"}
  ```
  expects:

  ```json
  {"ok":true,"setting":{"key":"imbib.retention.inbox_days"}}
  ```

## `settings-service_set`

Store a value. The value must have the declared type; a choice's label (`"1 Month"`) or the string spelling of a number or bool is accepted, anything else is refused and nothing changes. Writes the scope's file (or the synced row) so every app sees it.

- **safety**: `mutating`, idempotent
- **reads**: —
- **writes**: "impress/settings@1.0.0"
- **reach**: fs

| Argument | Type | Required | Description |
|---|---|---|---|
| `key` | string | yes | The registry key. |
| `value` | — | yes | The new value (JSON: a bool, number or string). |

**Examples**

- `set_inbox_days` — Tier A:

  ```json
  {"key":"imbib.retention.inbox_days","value":31}
  ```
  expects:

  ```json
  {"ok":true,"setting":{"key":"imbib.retention.inbox_days","value":31,"source":"stored"}}
  ```
