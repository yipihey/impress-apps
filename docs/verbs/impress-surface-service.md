## `impress-surface-service_surface-create`

Store a spec as a new `impress/ui/surface@1.0.0` row, after validating it exactly as `surface_validate` does: a spec with an error is refused (`invalid-spec`, every problem in `problems`) and nothing is stored; warnings are stored and listed. `name` overrides the row's label (the spec's own `name` is untouched); `tags` are free-text labels shown by `surface_list`.

- **safety**: `mutating`
- **reads**: "impress/ui/surface@1.0.0"
- **writes**: "impress/ui/surface@1.0.0"
- **reach**: —

| Argument | Type | Required | Description |
|---|---|---|---|
| `name` | — | no | The row's label; the spec's own `name` when absent. |
| `spec` | object | yes | The spec, as JSON. Validated first; refused with every problem if it has an error. |
| `tags` | — | no | Free-text labels. |

**Examples**

- `g3-create` — Tier A:

  ```json
  {"spec":{"surface":"1.0","name":"G3 surface","state":{"message":"ready"},"root":{"column":[{"text":"{{state.message}}","id":"message"},{"button":{"label":"Set message","on_click":[{"set":{"path":"state.message","value":"done"}},{"emit":{"name":"changed","payload":{"message":"{{state.message}}"}}}]},"id":"set-message"}]}}}
  ```
  expects:

  ```json
  {"ok":true}
  ```

## `impress-surface-service_surface-dispatch`

Reduce one renderer event (`{"widget", "kind", "value"}`), persist the resulting state, run every effect it produced, and re-render — as the agent. `ok` only when every effect happened. `params` as for `surface_render`.

- **safety**: `mutating`
- **reads**: "impress/ui/surface@1.0.0", "impress/ui/surface-state@1.0.0", any("evaluates the surface's verb sources")
- **writes**: "impress/ui/surface-state@1.0.0", "impress/ui/surface-event@1.0.0", any("runs the surface's actions")
- **reach**: —

| Argument | Type | Required | Description |
|---|---|---|---|
| `event` | — | yes | {"widget": id, "kind": "change"\|"click"\|"select"\|"submit", "value": json}. |
| `host` | — | no | State instance identifier; defaults to this device. |
| `id` | string | yes | UUID of the stored surface returned by surface-create or surface-list. |
| `params` | — | no | Surface parameter bindings by name; defaults to those of the showing pane. |

**Examples**

- `g3-dispatch` — Tier A:

  ```json
  {"id":"66000000-0000-4000-8000-000000000010","host":"g3-surface-examples","event":{"widget":"set-message","kind":"click","value":null}}
  ```

## `impress-surface-service_surface-show`

- **writes**: "impress/ui/surface@1.0.0"

| `host` | — | no | State instance identifier; defaults to this device. |
| `id` | string | yes | UUID of the stored surface returned by surface-create or surface-list. |
