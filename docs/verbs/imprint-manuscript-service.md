## `imprint-manuscript-service_compile-typst`

Compile Typst source to a PDF and return `pdf_path` (plus page count and any warnings) — NOT the bytes, which no tool result can carry. Feed `pdf_path` to `render_pdf_page` to actually look at a page. Works with imprint closed: the compiler is embedded. With imprint running the compile happens in its live engine instead; either way you get a path. A broken document comes back as `error`, not as a failed call.

- **safety**: `mutating`
- **reads**: "manuscript", "manuscript-file@1.0.0"
- **writes**: —
- **reach**: fs
