## `impress-workflow-service_workflow-create`

Store a spec as a new `impress/workflow@1.0.0` row, after validating it exactly as `workflow_validate` does — a spec with an error is refused (`invalid-spec`) and nothing is stored. **An agent caller's row is always `state: proposed`** (D-R6), whatever `spec.state` said; a person's row keeps the state the spec named.

- **safety**: `mutating`
- **reads**: "impress/workflow@1.0.0"
- **writes**: "impress/workflow@1.0.0"
- **reach**: —

| Argument | Type | Required | Description |
|---|---|---|---|
| `spec` | object | yes | Complete workflow document; agent callers always create a proposed workflow. |

**Examples**

- `manual macro` — Tier A:

  ```json
  {"spec": {"wire_version": 1, "name": "example", "state": "proposed", "author": {"kind": "agent", "name": "example"}, "trigger": {"manual": {}}, "steps": []}}
  ```

## `impress-workflow-service_workflow-dry-run`

`plan → resolve → reduce` with `event` (or `{}` when absent) as the trigger's own payload, and every `call` step returned as `would_call` rather than executed — the same table a review surface shows (plan § Workflows, "Dry run and validation").

- **safety**: `read_only`, idempotent
- **reads**: "impress/workflow@1.0.0"
- **writes**: —
- **reach**: —

| Argument | Type | Required | Description |
|---|---|---|---|
| `event` | — | no | Trigger payload used to resolve event templates; defaults to an empty object. |
| `id` | string | yes | UUID of the stored workflow to plan without running its steps. |

**Examples**

- `g3-plan-without-executing` — Tier A:

  ```json
  {"id":"64000000-0000-4000-8000-000000000002","event":{"flag":"red"}}
  ```
  expects:

  ```json

  ```

## `impress-workflow-service_workflow-validate`

Every problem with a workflow, by JSON pointer and severity: the surface validator's own structural checks over the synthetic spec `impress-workflow` builds, plus a `publish`/`open` step (refused — a workflow has no pane) and a `schedule` trigger under 60s. `ok` is false (`invalid-spec`) when any problem is an error.

- **safety**: `read_only`, idempotent
- **reads**: —
- **writes**: —
- **reach**: —

|---|---|---|---|
| `spec` | object | yes | Complete workflow document to validate without storing or executing it. |
