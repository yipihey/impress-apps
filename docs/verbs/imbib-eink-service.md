## `imbib-eink-service_eink-append-notes`

Append the imported highlights and notes to the paper's Notes field as one dated block. A snapshot already appended is skipped unless `force`; rows that carry no text yet (handwriting awaiting recognition) are an error, not a silent no-op. Never runs on its own.

- **safety**: `mutating`
- **reads**: "imbib/bibliography-entry", "imbib/linked-file", "imbib/annotation", "imbib/eink-mirror", "imbib/eink-device"
- **writes**: "imbib/bibliography-entry", "imbib/linked-file", "imbib/annotation"
- **reach**: —

| Argument | Type | Required | Description |
|---|---|---|---|
| `force` | boolean | yes | Append again even if this imported snapshot was already added to Notes. |
| `publication_id` | string | yes | UUID of the paper whose tablet annotations should be read or updated. |

**Examples**

- `g3-eink-append-notes` — Tier A:

  ```json
  {"publication_id":"6b000000-0000-4000-8000-000000000001","force":false}
  ```
  expects:

  ```json
  {"ok":true,"appended":true}
  ```

## `imbib-eink-service_eink-import-document`

Bring one such document into the store. `as_kind` `publication` (default: a notebook becomes a `@misc` entry with the rendered PDF as its file; a PDF/ePUB whose bytes match a file already here adopts that publication) or `note` (an `impress/artifact/note`). The library may be omitted for a document under `imbib/<Library>`.

- **safety**: `external`
- **reads**: "imbib/eink-device", "imbib/eink-mirror", "imbib/library", "imbib/bibliography-entry"
- **writes**: "imbib/bibliography-entry", "imbib/linked-file", "imbib/eink-mirror", "impress/artifact/note"
- **reach**: device, fs

| Argument | Type | Required | Description |
|---|---|---|---|
| `as_kind` | — | no | Import as publication or note; defaults to publication. |
| `collection_id` | — | no | Destination collection UUID; omit for no collection assignment. |
| `device_id` | — | no | Configured tablet UUID; omit to use the default tablet. |
| `library_id` | — | no | Destination library UUID; omit to infer it from the tablet folder. |
| `remote_id` | string | yes | Document identifier reported by eink-list-unmatched on the selected tablet. |

**Examples**

